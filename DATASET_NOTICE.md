# Dataset source and reuse

AuditScribe uses selected public audit prose from https://github.com/solodit/solodit_content at revision `4d5330d12978c7a8fc2aab5b171112784fb671bd`.

The inspected repository has no repository-wide LICENSE file. Public accessibility does not establish a blanket redistribution licence for the individual auditors' reports. Report text remains attributable to the original authors and rights holders. This project provides acquisition code, document source links and hashes rather than republishing the raw or processed corpus. Check each source's applicable terms before redistributing report text or using it commercially. AuditScribe code licensing does not apply to third-party reports.

The local SQLite database, windows and checkpoints are excluded from the public package. They are regenerated by the documented commands. Generated continuations are experimental model outputs and are not original audited findings or security recommendations.
